# 🌯 موقع ومنيو مطعم موحا (نسخة محسّنة)

موقع منيو تفاعلي (HTML + CSS + JavaScript بدون أي مكتبات) مع سلة طلبات وإرسال على واتساب.

## 📁 هيكل الملفات

```
index.html        ← الصفحة (الهيكل فقط)
css/style.css     ← التصميم
js/config.js      ← ⚙️ الإعدادات (واتساب، توصيل، دفع، أرقام، عنوان)
js/menu.js        ← 🍔 المنيو (الأصناف والأسعار)
js/app.js         ← منطق الموقع (لا تحتاج تعدله)
manifest.json     ← إعدادات تثبيت الموقع كتطبيق على الموبايل
assets/           ← الأيقونات وصورة المشاركة (og-image.png)
```

## ✏️ إزاي تعدّل؟

### تغيير سعر أو اسم صنف — `js/menu.js`
```js
{ "id": "burger-1", "name": "سماش برجر", "price": 90 }
```
### إضافة صنف جديد
أضف سطر جديد داخل القسم المطلوب بـ `id` **فريد** (لا يتكرر):
```js
{ "id": "burger-13", "name": "برجر جديد", "price": 110, "desc": "وصف اختياري", "badge": "جديد" }
```
### صنف خلص؟
```js
{ "id": "roll-2", "name": "رول فريش", "price": 110, "available": false }
```
### إضافة صورة لصنف
حط الصورة في `assets/img/` وأضف: `"image": "assets/img/اسم-الصورة.jpg"`

### الإعدادات — `js/config.js`
| الإعداد | الوظيفة |
|---|---|
| `whatsappNumber` | رقم واتساب (صيغة دولية بدون +) |
| `deliveryFee` | رسوم التوصيل (`null` = تتحدد عند التأكيد، `0` = مجاني، أو رقم) |
| `freeDeliveryFrom` | توصيل مجاني لو الطلب وصل لمبلغ معين |
| `minOrder` | أقل قيمة طلب للتوصيل |
| `paymentMethods` | طرق الدفع |
| `address` / `phones` / `workingHours` / `mapUrl` | بيانات الفوتر |

## ✅ إيه اللي اتحسّن عن النسخة القديمة؟

- المنيو بقى **في ملف بيانات واحد** (63 صنف) بدل HTML مكرر، وكل صنف له `id` ثابت.
- **سلة كاملة** (نافذة مراجعة): زيادة/نقص/حذف/تفريغ، وتتحفظ لو الصفحة اتعملها refresh.
- **توصيل أو استلام من الفرع**، رسوم توصيل، حد أدنى، توصيل مجاني بشرط، **طرق دفع**.
- **تحقق من البيانات** برسائل تحت الحقول (رقم موبايل مصري، عنوان، اسم) بدل `alert`.
- يتذكر بيانات العميل للطلب الجاي.
- **بحث** في المنيو (بيتجاهل الفروق بين أ/ا و ة/ه).
- شريط الأقسام **ثابت فوق** وبيتحدد تلقائي مع السكرول.
- حالة "غير متاح"، وبادج للأصناف ("الأكثر طلبًا")، ودعم صور الأصناف.
- **SEO ومشاركة:** meta description + Open Graph + Schema.org (Restaurant) + favicon.
- أرقام الهاتف روابط `tel:`، وزر الخريطة، وساعات العمل.
- **Accessibility:** `aria-label` للأزرار، `autocomplete` و`inputmode` للحقول، دعم لوحة المفاتيح (Esc يقفل السلة).
- **PWA مبدئي:** `manifest.json` يخلي العميل يثبت الموقع على شاشة الموبايل.
- توحيد الاسم: "الفرنساوي" في كل مكان، واسم المطعم "موحا" في رسالة واتساب.

## ⚠️ لازم تعمله بعد الرفع

1. في `index.html` استبدل **`YOUR-USERNAME`** باسم حسابك على GitHub (في `og:image` و `og:url`)، عشان كارت المشاركة يظهر صح.
2. حدّد في `config.js`: `deliveryFee` و `minOrder` و `workingHours` و `mapUrl`.
3. راجع الأسعار: الأصناف الصغيرة (5 / 20 / 25 / 30 ج) إضافات، اتأكد إنها مقصودة.
4. استبدل `assets/og-image.png` وأيقونات `icon-*.png` بتصميم اللوجو الحقيقي.

## 🚀 الرفع على GitHub Pages

1. أنشئ Repository جديد (مثلاً `mo7a-menu`).
2. ارفع **كل الملفات والمجلدات** (مش `index.html` بس).
3. Settings ← Pages ← Branch: `main` ← Save.
4. الرابط هيظهر خلال دقيقة: `https://USERNAME.github.io/mo7a-menu/`

> لتجربة الموقع على جهازك: افتح `index.html` مباشرة في المتصفح.

## 🔮 أفكار للمرحلة الجاية

- صور حقيقية للأصناف (أكبر تأثير على المبيعات).
- اختيارات لكل صنف (حجم / إضافات) بدل الملاحظات.
- Google Analytics أو Meta Pixel لو هتعمل إعلانات.
- Service Worker لو عايز الموقع يشتغل أوفلاين.
